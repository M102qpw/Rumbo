# Rumbo

App personal para planear recorridos de viaje: paradas, rutas a pie, transporte público,
pasajes, horario del día y modo viaje. Se comparte con familia y amigas.

- `app/` – app Android (Kotlin + Jetpack Compose + MapLibre + Firebase)
- `docs/` – página para invitados (se publica con GitHub Pages)

Datos de mapas © OpenStreetMap. Rutas en transporte: [Transitous](https://transitous.org/sources/).
